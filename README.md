## ✨ Features

| Feature | Details |
|---|---|
| 🛍️ **Product Catalog** | 28 real products with Unsplash imagery across 5 departments (Fashion, Electronics, Home, Beauty, Sport) |
| 🛒 **Shopping Cart** | Full add/remove/quantity controls, persistent via localStorage |
| ❤️ **Wishlist** | Save favorites with local persistence |
| 🔍 **Live Search** | Instant product search across all departments |
| 📦 **Multi-Step Checkout** | Shipping form, payment options (Card, COD, JazzCash/EasyPaisa), order confirmation |
| 🔐 **Auth System** | Login / Sign up with demo admin credentials |
| 🧑‍💼 **Admin Dashboard** | Product management, order overview, stats dashboard |
| 📝 **Blog Section** | Article cards + individual article pages |
| 💱 **Multi-Currency** | USD ⇄ PKR real-time switching (rate: 280) |
| 🌐 **Bilingual** | English ⇄ Urdu with full RTL layout support |
| 🌓 **Dark/Light Mode** | Theme toggle with system preference detection & persistence |
| 🎬 **Animations** | Smooth fade-in reveals, parallax scrolling, hover zoom/glow, 3D card tilts, marquee |
| 🎨 **Design System** | Blue / White / Sandy color palette with consistent tokens |
| 📱 **Fully Responsive** | Optimized for desktop, tablet, and mobile |
| ⚡ **Zero Dependencies** | Pure HTML / CSS / JavaScript — single file, no build step |

## 🛠️ Tech Stack

- **HTML5** — Semantic markup, SPA via hash routing
- **CSS3** — Custom properties (design tokens), grid, flexbox, keyframe animations, backdrop-filter, dark mode, media queries
- **Vanilla JavaScript (ES6+)** — Component rendering, IntersectionObserver, localStorage, event delegation, client-side routing
- **Google Fonts** — Fraunces (display), Manrope (body), IBM Plex Mono (monospace), Noto Nastaliq Urdu
- **FontAwesome 6** — Icons
- **Unsplash** — Real product photography

## 🏃 Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/shehryar-spec/zevora-ecommerce.git

# 2. Navigate to the project folder
cd zevora-ecommerce

# 3. Open in browser (no build needed!)
open index.html        # macOS
start index.html       # Windows
xdg-open index.html    # Linux
```

> **No npm install, no build step, no server required.** Just open `index.html` in any modern browser.

## 🎯 Design Highlights

- **Color Palette**: Deep navy (`#0E2A47`) → Royal blue (`#1E6FBF`) → Sandy cream (`#F6F1E7`) with gold accents
- **Typography**: Fraunces (editorial display serif) paired with Manrope (clean geometric sans) and IBM Plex Mono (labels/tags)
- **Micro-interactions**: Button fill animations, card tilts on cursor, image zoom on hover, glowing focus states
- **Parallax System**: requestAnimationFrame-throttled layered depth on hero, promo slider, and newsletter
- **Accessibility**: Semantic HTML, focus outlines, `prefers-reduced-motion` support, keyboard-navigable
