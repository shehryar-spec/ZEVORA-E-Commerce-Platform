## ✨ Features

| Feature | Details |
|---|---|
| 🛍️ **Product Catalog** | 28 real products across 5 departments (Fashion, Electronics, Home, Beauty, Sport) |
| 🛒 **Shopping Cart** | Full add/remove/quantity controls, persistent via localStorage |
| ❤️ **Wishlist** | Save favorites with local persistence |
| 🔍 **Live Search** | Instant product search across all departments |
| 📦 **Multi-Step Checkout** | Shipping form, payment options (Card, COD, JazzCash/EasyPaisa) |
| 🔐 **Auth System** | Login / Sign up with demo admin credentials |
| 🧑‍💼 **Admin Dashboard** | Product management, order overview, stats dashboard |
| 📝 **Blog Section** | Article cards + individual article pages |
| 💱 **Multi-Currency** | USD ⇄ PKR real-time switching |
| 🌐 **Bilingual** | English ⇄ Urdu with full RTL layout support |
| 🌓 **Dark/Light Mode** | Theme toggle with system preference detection |
| 🎬 **Animations** | Smooth fade-in reveals, parallax scrolling, hover zoom/glow, 3D card tilts |
| 🎨 **Design System** | Blue / White / Sandy color palette |
| 📱 **Fully Responsive** | Optimized for desktop, tablet, and mobile |
| ⚡ **Zero Dependencies** | Pure HTML / CSS / JavaScript — single file, no build step |

---

## 🛠️ Tech Stack

- **HTML5** — Semantic markup, SPA via hash routing
- **CSS3** — Custom properties, grid, flexbox, keyframe animations, dark mode
- **Vanilla JavaScript (ES6+)** — Component rendering, IntersectionObserver, localStorage
- **Google Fonts** — Fraunces, Manrope, IBM Plex Mono, Noto Nastaliq Urdu
- **FontAwesome 6** — Icons
- **Unsplash** — Real product photography

## 🏃 Quick Start

```bash
# 1. Clone or download this repository
# 2. Just open index.html in any modern browser
open index.html        # macOS
start index.html       # Windows
```

> **No npm install, no build step, no server required.** Just open `index.html` — it works.

## 🎯 Design Highlights

- **Color Palette**: Deep navy → Royal blue → Sandy cream with gold accents
- **Typography**: Fraunces (editorial serif) + Manrope (sans) + IBM Plex Mono
- **Micro-interactions**: Button fills, card tilts, image zoom on hover
- **Parallax**: requestAnimationFrame-throttled layered depth
- **Accessibility**: Semantic HTML, focus outlines, prefers-reduced-motion support
